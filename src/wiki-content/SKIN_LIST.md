# 스킨 모음집 (함순이 스킨검색기)

> **URL**: https://jforplay.github.io/altoy/skin/skin-list-viewer/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 스킨 & 대사

전체 스킨을 필터링해서 한눈에 보는 스킨 도감. 판매중 정보까지 같이 표시돼서 스킨 살 때 참고하기 좋음.

![스킨 검색기](/altoy/wiki-assets/SKIN_LIST/01-main.webp)
*필터 패널 + 판매 중인 신상/복각 스킨 섹션*

## 주요 기능
- **각종 필터**: 함순이/스킨 이름 검색, 스킨 타입, 스킨 태그(L2D 등), 진영, 스킨 테마, 가격 등으로 추려볼 수 있음
- **판매중 표시**: 그때그때 상점에 판매 들어오는 신규/복각 한정 스킨이 별도 섹션으로 표시됨
- **보유/찜 기능**: 스킨에 보유/찜 표시를 해두면 장바구니처럼 가격 계산이 되고, 보유 스킨 관리장부로도 쓸 수 있음 (구글 드라이브 동기화 지원)
- **URL 연동**: 필터를 걸면 URL도 같이 바뀌어서 필터링 상태 그대로 공유 가능
- **상세 연동**: 그림 누르면 해당 스킨의 일러/대사 페이지로 이동, `i` 버튼으로 tmi 확인
