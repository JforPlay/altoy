# 기타 BGM (앨범에 포함되지 않은 BGM)

> **URL**: https://jforplay.github.io/altoy/misc/bgm-misc/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 그 외 컨텐츠

정식 앨범에 안 들어간 BGM 497곡을 모아둔 보관소. 이벤트 브금이나 효과성 트랙처럼 앨범으로 정리 안 된 것들을 여기서 찾으면 됨.

![기타 BGM](/altoy/wiki-assets/BGM_MISC/01-main.webp)
*파일명/원제목 검색 + 트랙 목록 + 재생/즐겨찾기*

## 주요 기능
- **출처별 분류**: 이벤트 / 메인 스토리 / 해역 / 작전 시렌 / 기숙사 가구 등 게임에서 실제로 쓰이는 곳별로 묶어서 표시. 그룹 제목을 누르면 접기/펼치기
- **사용처·연도 표시**: 각 트랙 아래에 등장 연도와 사용처(이벤트명, 스킨명, 가구명 등) 표시
- **정렬**: 최신순(기본) / 오래된순 / 이름순
- **검색**: 파일 이름, 원제목, 사용처 이름으로 검색
- **재생**: 트랙별 재생 버튼
- **즐겨찾기**: 하트 표시로 자주 듣는 곡 관리
