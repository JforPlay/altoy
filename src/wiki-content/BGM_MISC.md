# 기타 BGM (앨범에 포함되지 않은 BGM)

> **URL**: https://jforplay.github.io/altoy/misc/bgm-misc/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 그 외 컨텐츠

정식 앨범에 안 들어간 BGM 493곡을 모아둔 보관소. 이벤트 브금이나 효과성 트랙처럼 앨범으로 정리 안 된 것들을 여기서 찾으면 됨.

![기타 BGM](/altoy/wiki-assets/BGM_MISC/01-main.webp)
*파일명/원제목 검색 + 트랙 목록 + 재생/즐겨찾기*

## 주요 기능
- **검색**: 파일 이름 또는 원제목으로 검색
- **재생**: 트랙별 재생 버튼
- **즐겨찾기**: 하트 표시로 자주 듣는 곡 관리
