# 룽섭 일정보기 (벽람항로 룽섭이벤트 전체보기)

> **URL**: https://jforplay.github.io/altoy/event-timeline/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 계산기/도구

과거 룽섭 이벤트 일정(240개+)을 검색/필터와 함께 쭉 볼 수 있는 페이지.

![이벤트 목록](/altoy/wiki-assets/EVENT_TIMELINE/01-main.webp)
*검색 + 필터 + 이벤트 카드(날짜/무딱 여부/임무 보상/등장 함순이)*

## 주요 기능
- **검색**: 이벤트명 또는 함순이 이름으로 검색
- **필터링**: 이벤트 분류 / 진영 / 무딱이벤여부 / 복각·상시현황으로 추려보기 가능
  - 예) 무딱이벤여부 → O로 두면 무딱 있었던 이벤만, 복각/상시현황 → 상시만 두면 상시 편입된 이벤트만
- **일섭기반 일정 포함**: 정리 안 된 일섭기반 일정까지 포함해서 보는 체크박스
- **연동**: `상세보기` 있는 이벤트는 누르면 챈 정보글로 이동, 등장 함순이를 누르면 함순이 DB 상세로 이동

## 보기 방식 3가지
목록 위 버튼으로 전환. 검색/필터는 어느 보기에서든 그대로 먹음.

- **타임라인**: 기본. 이벤트 카드를 시간순으로 쭉 나열. 복각/상시 카드를 누르면
  같은 이벤트의 신규→복각→상시 런들이 서로 연결돼서 표시됨
- **이벤트별**: 같은 이벤트의 신규/복각/상시를 한 카드로 묶어서 보여줌.
  "이 이벤트 몇 번 복각됐지?" 볼 때 편함

![이벤트별 보기](/altoy/wiki-assets/EVENT_TIMELINE/02-groups.webp)
*한 카드에 신규 → 복각 → 상시가 며칠 간격이었는지까지 표시*

- **무딱 타임라인**: 무딱 있었던 이벤트만 모아서 월 단위 가로 차트로 표시.
  한 줄이 한 이벤트고, 신규→복각→상시 흐름이 한눈에 보임
  - **기본 보기**: 실제 연월 축. 언제 뭐가 있었나 보는 용도
  - **복각주기 보기**: 각 이벤트의 첫 런을 0으로 맞춰서 다시 그림.
    "보통 몇 개월 만에 복각되나" 이벤트끼리 비교할 때 사용
    (복각/상시 이력 있는 무딱 이벤트만 나옴)

![무딱 타임라인 - 기본 보기](/altoy/wiki-assets/EVENT_TIMELINE/03-mudak.webp)
*기본 보기 — 실제 연월 축. 초록 = 복각 대기, 파랑 = 상시 대기, 분홍 = 상시 플레이 가능*

![무딱 타임라인 - 복각주기 보기](/altoy/wiki-assets/EVENT_TIMELINE/04-mudak-relative.webp)
*복각주기 보기 — 첫 런을 0개월로 맞춰서 이벤트끼리 복각 주기를 나란히 비교*

## 참고
- 챈에서 찾을 수 있는 굵직한 이벤트들 말고는 수작업으로 정리된 거라 약간 찐빠가 있을 수 있음 — 제보 환영
