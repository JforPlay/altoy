# 장비 연구 (기어 랩 연구 트리)

> **URL**: https://jforplay.github.io/altoy/equip/equip-upgrade/
>
> **내비게이션 바 위치**: 정보/도구모음 → 장비 관련

기어 랩(장비 연구)의 업그레이드 트리를 진영×함종별로 보여주는 페이지.

![연구 트리](/altoy/wiki-assets/EQUIP_UPGRADE/01-main.webp)
*진영/함종 선택 → 장비 업그레이드 체인*

## 주요 기능
- **진영 × 함종 트리**: 이글 유니온 / 로열 네이비 / 사쿠라 엠파이어 / 철혈 / 사르데냐 / 북방연합 / 아이리스·비시아 × 함포/어뢰/함재기 등으로 업그레이드 경로를 한눈에 확인
- **노드 상세**: 트리에서 장비를 누르면 아래에 해당 장비 정보가 나오고, 장비 DB 상세로 바로 이동할 수도 있음
- **재료 목록**: 오른쪽 위 `재료 목록` 버튼으로 연구에 필요한 재료들을 확인 가능

![노드 선택](/altoy/wiki-assets/EQUIP_UPGRADE/02-detail.webp)
*노드 선택 시 하단에 장비 정보 표시*
