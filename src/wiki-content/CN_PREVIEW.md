# (스포주의) 중섭패치 미리보기

> **URL**: https://jforplay.github.io/altoy/shipgirl/cn-preview/
>
> **내비게이션 바 위치**: 없음 — 메인 페이지의 「(스포주의) 중섭패치 미리보기」 카드 또는 Ctrl+K 검색으로 진입

중국 서버에 먼저 추가됐고 한국 서버에는 아직 없는 함순이와 스킨을 모아 보여주는 페이지야. 보통 2주 정도 앞선 컨텐츠라서, 다음 업데이트에 뭐가 오는지 미리 볼 수 있어. 한섭에 정식으로 나오기 전 내용이라 메뉴에는 넣지 않았어.

## 주요 기능
- **신규 함순이 / 신규 스킨** 두 가지 보기를 상단 버튼으로 전환
- **신규 함순이**: 일러, 레어도, 진영/함종, 기본 스탯, 스킬 설명(중국어 원문). 카드의 「스킨 / 대사 보기」 버튼을 누르면 그 함순이의 스킨 화면으로 바로 이동
- **신규 스킨**: 위쪽 목록에서 스킨을 고르면 아래에 상세가 나와. 스킨/대사보기 페이지와 같은 구성이라 **표정 선택**, 확대 일러, 클릭 확대(라이트박스), 이미지 저장이 그대로 돼
- 스킨 상세 맨 아래에 **대사 표**가 있고, 재생 버튼으로 바로 들을 수 있어 (음성은 일본어 원음, 볼륨 조절 가능)
- 각 카드/타일에 중국 서버에 처음 등장한 날짜(`CN yyyy-mm-dd`)를 표시

## 팁
- 텍스트는 번역 없이 중국어 원문 그대로야. 한국 서버 출시 시 이름·설명·기간이 바뀔 수 있어.
- 차이가 없으면 「현재 KR과 CN 컨텐츠 차이가 없습니다」라고만 나와.
- 이미지/음성이 비어 있는 카드는 아직 클라이언트에 에셋이 없는 거야. 다음 갱신 때 채워져.
