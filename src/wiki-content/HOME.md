# 메인화면

> **URL**: https://jforplay.github.io/altoy/
>
> **새 주소**: https://altoy.pages.dev/ (업데이트 반영이 더 빠름)

ALtoy의 시작 페이지. 아래 소개되는 모든 페이지는 위쪽 메뉴바(4개 대분류 드롭다운)를 통해서 찾아갈 수 있음. 메인에는 진행 중인 이벤트랑 다가오는 함순이 생일 같은 것들이 바로 보이게 되어있음.

![메인화면](/altoy/wiki-assets/HOME/01-main.webp)
*상단 배너 캐러셀 + 다가오는 생일 / 진행 중인 이벤트 / 안내사항 위젯*

## 주요 기능
- **메뉴바**: `함순이/스킨/대사`, `정보/도구모음`, `스토리보기`, `인게임 컨텐츠` 4개 드롭다운으로 모든 페이지 이동 가능. 모바일에서는 햄버거 메뉴로 동일하게 사용 가능함
- **전역 검색 (Ctrl+K)**: 메뉴바의 돋보기를 누르거나 `Ctrl+K`를 누르면 검색창이 뜸. 결과는 페이지 / 함순이 / 장비 세 갈래로 나눠서 보여줌. 페이지 이름으로 검색하면 해당 페이지로 바로 이동하고, 함순이 이름으로 검색하면 옆의 작은 아이콘으로 함순이 DB / 스킨 뷰어 / 발렌타인 편지로, 장비는 장비 DB / 장비 연구로 바로 보내줌. 장비는 정식 명칭 말고 **별명**(백탄, 다메콘 등)으로도 검색됨
- **다크모드**: 달/해 아이콘으로 전환. 모든 페이지에 적용됨
- **데이터 동기화 (구름 아이콘)**: 트래커류 진행상황(육성트래커, 개발함 트래커, 스킨 찜/보유, 아일랜드 진행 등)을 본인 구글 드라이브에 백업해서 다른 기기와 동기화할 수 있음. 수동 동기화 방식이고 데이터는 본인 드라이브에만 저장됨
- **진행 중인 이벤트 / 다가오는 생일**: 메인에서 바로 확인 가능

## 팁
- 어느 페이지에 뭐가 있는지 모르겠으면 일단 `Ctrl+K` 누르고 생각나는 단어를 쳐보는게 제일 빠름
