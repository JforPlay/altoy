# 해역 정보

> **URL**: https://jforplay.github.io/altoy/map/map-viewer/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 계산기/도구

해역 맵, 소모 연료/탄약, 적 함대, 드랍, 별 조건 같은 해역 정보를 모아둔 페이지. 해역끼리 비교하는 기능도 있음.

![해역 선택](/altoy/wiki-assets/MAP_VIEWER/02-map.webp)
*1-1 선택 — 맵 그리드(출격/일반/보스 노드), 소모 정보, 별 조건, 클리어 정보*

## 주요 기능
- **탭 구성**: 메인 해역 / 하드 해역 / 이벤트 해역 / 작전 문서 / 대형 작전까지 전부 지원
- **해역 상세**: 맵 그리드(출격 위치, 일반/보스 노드, 이동불가 칸), 연료/탄약 소모, 제공치, 보스 출현 조건, 함대 수, 기름 상한 여부, 별 조건, 클리어 정보(전투 횟수/EXP)까지 확인 가능
- **드랍 정보**: 작전문서(작문)의 경우 알아두면 좋을 드랍 함순이 위주로 정리되어 있음
- **함순이 검색 / 설계도 검색**: 오른쪽 위 버튼으로 "이 함순이 어디서 드랍?" / "이 설계도 어디서 파밍?"을 역으로 검색 가능
- **비교하기**: 해역을 띄운 상태에서 비교 모드로 들어가면 다른 해역과 효율 비교를 할 수 있음
- **URL 공유**: `?map=ID&tab=탭`으로 특정 해역 바로 공유 가능
