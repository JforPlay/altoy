# 비서함 스토리 (비서함 스토리 뷰어)

> **URL**: https://jforplay.github.io/altoy/story-viewer/secretary-story/
>
> **내비게이션 바 위치**: 스토리보기 → 기타 스토리 컨텐츠

비서함으로 세워두고 모항에서 터치하면 시작되는 비서함 퀘스트 스토리 모음. 체크 기능이 있어서 어디까지 봤는지 체크리스트처럼 관리할 수 있음.

![함순이 목록](/altoy/wiki-assets/SECRETARY_STORY/01-main.webp)
*비서함 퀘스트가 있는 함순이들 + 진영/완료 필터*

## 주요 기능
- **함순이별 퀘스트 목록**: 함순이를 누르면 해당 비서함퀘 단계들(부탁 1, 2, ...)과 각 단계의 발생 조건이 나옴
- **체크리스트**: 본 스토리/완료한 퀘스트를 체크해두면 저장됨 — 진행상황 관리용으로 쓰기 좋음
- **스토리 감상**: 각 퀘스트의 스토리를 뷰어로 바로 감상 가능 (브금 자동재생 주의 알림 있음)

![퀘스트 목록](/altoy/wiki-assets/SECRETARY_STORY/02-detail.webp)
*아카시 비서함퀘 — 단계별 부탁 목록과 조건*

## 팁
- 아카시퀘는 상점에서 아카시를 30회쯤 연타하면 시작되는 연계퀘임
