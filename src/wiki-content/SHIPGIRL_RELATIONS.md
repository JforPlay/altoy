# 함순이 관계도

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-relations/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 정보

전체 함순이를 한 장의 관계 지도로 보는 페이지. 진영이 하나의 "나라", 같은 함급 자매함이 그 안의 "지역"으로 묶여 있고, 함순이끼리 이어진 선마다 왜 이어졌는지(함대 특수대사, 대사 속 언급, 같이 나온 스토리, JUUS)를 바로 확인할 수 있음.

![함순이 관계도](/altoy/wiki-assets/SHIPGIRL_RELATIONS/01-main.webp)
*전체 보기 — 진영별 나라와 함급 지역, 근거별 색깔 선*

## 주요 기능
- **전체 지도**: 휠/핀치로 확대, 드래그로 이동. 멀리서는 진영 이름과 선만, 가까이 가면 함급 이름, 더 가까이 가면 함순이 아이콘과 이름이 보임. 이름이 겹칠 자리에서는 함순이 이름을 숨기고, 마우스를 올리거나 선택하면 보여줌. 확대해서 진영 이름이 화면 밖으로 나가면 화면 가장자리에 붙여서 보여줌
- **선 굵기 = 관계 점수, 선 색 = 가장 큰 근거**: 함대 특수대사(주황) / 언급(파랑) / 스토리(보라) / JUUS(초록). 원 크기는 연결된 함순이 수
- **선택하면 근거가 보임**: 함순이를 클릭하면 이어진 선만 밝게 남고 오른쪽 패널에 연결 목록이 뜸. 함대 특수대사는 "누가 같이 출격해야 나오는 대사인지"(예: `대처·얼릭·푸트·스펜스 중 2명과 함께 출격하면`)까지 정확하게 표시하고 ▶로 바로 들어볼 수 있음. 언급은 대사 속 이름에 하이라이트, 스토리는 제목을 누르면 해당 스토리로 이동
- **패널에서 이어서 탐색**: 패널의 함순이를 누르면 그 함순이로 선택이 넘어가고 지도도 따라감. 이름을 누르면 함순이 DB로 이동
- **함급**: 같은 진영의 자매함은 점선 테두리로 묶여 있고, 선택하면 자매함까지 점선으로 이어줌. 다른 연결이 없는 자매함은 패널 아래쪽에 따로 모아줌
- **필터**: 근거 종류별 칩을 끄고 켜면 선이 바로 다시 계산됨(지도 배치는 그대로). 최소 점수 슬라이더로 약한 연결을 숨길 수 있음
- **검색**: 이름을 입력하고 Enter를 누르면 해당 함순이로 바로 이동
- **진영 바로가기**: 진영 이름이나 나라 안의 빈 곳을 누르면 그 진영으로 확대

*함순이 선택 — 연결된 선만 강조되고 패널에 근거가 표시됨*

## 팁
- META·μ장비 함순이는 원래 함순이와 별개로 취급함. "새러토가"라는 대사는 새러토가에만 이어지고, 새러토가·META는 정확히 그 이름이 나와야 이어짐
- 함대 특수대사는 편성으로 재생되는 대사라 대사 안에 상대 이름이 없는 경우가 많음. 패널의 "○○와 함께 출격하면" 부분이 상대를 알려줌
- 링크로 공유할 때는 주소 끝의 `?gid=` 값이 선택된 함순이를 가리킴. 그대로 보내면 같은 함순이가 선택된 상태로 열림
- 아직 별명(오이겐, 폐하 등)이나 "언니/동생" 같은 호칭은 잡지 못함. 이름이 그대로 나온 대사만 언급으로 셈
