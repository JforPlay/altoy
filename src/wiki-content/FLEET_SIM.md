# 편성 시뮬레이터

> **URL**: https://jforplay.github.io/altoy/simulators/fleet-sim/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 시뮬레이터들

함대를 짜보고 스탯/기술 보너스/장전 시간/데미지를 확인할 수 있는 편성 장난감. 후열(Main Fleet) 3칸 + 전열(Vanguard) 3칸 구조.

![편성 화면](/altoy/wiki-assets/FLEET_SIM/01-main.webp)
*후열/전열 슬롯 — `함순이 추가`를 눌러서 시작*

## 주요 기능
- **함순이 픽커**: 슬롯을 누르면 함종/레어도/진영 필터 + 이름 검색이 되는 선택창이 뜸
- **함순이 설정**: 슬롯에 넣은 함순이는 레벨(125 등), 호감도(사랑 등), 개조 여부를 조절할 수 있고, 칸별로 장비도 픽커로 장착 가능
- **장비 픽커 별명 검색**: 장비 이름 말고 별명으로도 찾아짐 (`노탄` → `91식 철갑탄` 같은 식)
- **전용 특수 장비**: 전용 장비가 있는 함순이는 마지막 칸에 자동으로 끼워지고, 다른 특수 장비로 바꾸거나 아예 빼둘 수도 있음. 강화 수치도 조절 가능
- **자동 계산**: 편성에 맞춰 스탯 합계, 기술 보너스, 패시브 스킬, 장전 시간 등이 계산됨
- **데미지 계산**: 타겟(경장/중형/중장 프리셋 또는 META 보스 + 티어)을 골라두면 무장별 데미지·DPS가 나오고, META 보스는 제한 시간 안에 잡히는지(✓/✗)까지 같이 보여줌
- **함대 4개까지**: 편성 위 `1함대 / 2함대 …` 탭으로 최대 4개를 따로 만들어두고 왔다 갔다 하면서 비교 가능. 서로 완전히 독립이고, 저장이나 공유 링크에도 전부 같이 담김
- **간략 보기**: 카드를 일러 + 장비 6칸만 남게 접어서 스샷 찍기 좋은 형태로 바꿔줌
- **장비 코드**: 카드마다 인게임 도크의 '장비 코드'와 똑같은 코드를 뽑거나 붙여넣을 수 있음. 인게임에서 복사한 코드를 그대로 가져오면 장비가 한 번에 세팅됨
- **저장/불러오기**: 여러 편성을 저장해두고 불러올 수 있음 (브라우저 저장). 저장한 편성은 이름을 바꾸거나 지금 편성으로 덮어쓸 수도 있음
- **공유**: `공유` 버튼으로 편성이 통째로 담긴 URL을 만들어서 다른 사람한테 보낼 수 있음
- **추천 편성**: 등록된 추천 편성이 있을 때만 상단에 `추천 편성` 버튼이 생김. 보스별 추천 편성을 눌러서 그대로 불러올 수 있음

## 팁
- 카드는 드래그해서 같은 열(후열끼리 / 전열끼리) 안에서 자리를 바꿀 수 있음
