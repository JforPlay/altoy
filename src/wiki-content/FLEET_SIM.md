# 편성 시뮬레이터

> **URL**: https://jforplay.github.io/altoy/simulators/fleet-sim/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 시뮬레이터들

함대를 짜보고 스탯/기술 보너스/장전 시간/데미지를 확인할 수 있는 편성 장난감. 후열(Main Fleet) 3칸 + 전열(Vanguard) 3칸 구조.

![편성 화면](/altoy/wiki-assets/FLEET_SIM/01-main.webp)
*후열/전열 슬롯 — `함순이 추가`를 눌러서 시작*

## 주요 기능
- **함순이 픽커**: 슬롯을 누르면 함종/레이드(등급)/진영 필터 + 이름 검색이 되는 선택창이 뜸
- **함순이 설정**: 슬롯에 넣은 함순이는 레벨(125 등), 호감도(사랑 등)를 조절할 수 있고, 칸별로 장비/특수장비도 픽커로 장착 가능
- **자동 계산**: 편성에 맞춰 스탯 합계, 기술 보너스, 패시브 스킬, 장전 시간 등이 계산됨. 무장/스킬 기반 데미지·DPS 확인 기능도 있음
- **저장/불러오기**: 여러 편성을 저장해두고 불러올 수 있음 (브라우저 저장)
- **공유**: `공유` 버튼으로 편성이 통째로 담긴 URL을 만들어서 다른 사람한테 보낼 수 있음

![함순이 선택창](/altoy/wiki-assets/FLEET_SIM/02-picker.webp)
*함순이 픽커 — 함종/레이드/진영 필터 + 검색*

![슬롯 채운 모습](/altoy/wiki-assets/FLEET_SIM/03-filled.webp)
*함순이 배치 후 — 레벨/호감도/장비 슬롯과 스탯 패널*
