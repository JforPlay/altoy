# 함순이 통계

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-stats/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 정보

재미로 보는 함순이/스킨 통계 페이지. 함순이 통계와 스킨 통계 두 탭으로 나뉘어 있고, 필터를 걸면 차트와 표가 같이 바뀜.

![함순이 통계](/altoy/wiki-assets/SHIPGIRL_STATS/01-main.webp)
*함순이 통계 탭 — 등급 요약 + 함종/진영 분포 차트*

## 주요 기능
- **함순이 통계 탭**: 총 함순이 수와 등급별(N~UR) 분포, 함종 분포, 진영 분포 차트. 이름 검색 + 등급/함종/진영 필터로 원하는 범위만 잘라서 볼 수 있음
- **개조 반영**: `개조 표시`를 켜두면 개조 함순이를 개조 후 기준(스탯·등급·함종)으로 집계함. 등급이 한 단계 올라가고(헬레나 SR → 헬레나·改 SSR) 함종이 바뀌는 함순이(모가미 경순→중순, 후소·이세 전함→항전 등)도 필터·차트에 그대로 반영됨. 끄면 개조 전 기준으로 돌아감
- **개조 가능만**: 개조가 있는 함순이만 추려서 봄. `개조 표시`와 따로 노는 토글이라, 개조 함순이를 개조 전 스탯으로 보는 것도 가능
- **PR/DR 필터**: 연구 함순이는 등급 필터에서 SSR/UR 아래에 PR/DR로 따로 잡혀 있음. SSR을 누르면 PR까지 전부, PR만 누르면 연구 SSR만 보이는 식
- **스킨 통계 탭**: 총 스킨 수, 함순이당 평균 스킨 수, L2D/L2D+/듀얼/쁘띠모션 개수 같은 요약과 태그 분포, 스킨 많은 함순이 TOP 랭킹까지 확인 가능
- **필터 연동**: 모든 차트/표가 위쪽 필터(등급/함종/진영/스킨 타입)에 실시간으로 반응함
