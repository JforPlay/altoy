# 쥬쥬 핫 이슈 (쥬스타그램 공식 계정 게시글)

> **URL**: https://jforplay.github.io/altoy/chat-viewer/juus-hot-issue/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 소셜 컨텐츠

쥬스타그램 공식 계정(쥬쥬 핫 이슈)의 게시글들을 모아둔 페이지. 모항 뉴스/모항 이야기/트렌디 모항 같은 인게임 공지 느낌의 글들을 볼 수 있음.

![게시글 목록](/altoy/wiki-assets/CHAT_JUUS_HOT_ISSUE/01-main.webp)
*공식 계정 게시글 카드 목록*

## 주요 기능
- **게시글 모아보기**: 번호(#20001~)순으로 정리된 공식 계정 게시글들
- **본문/이미지 보기**: 카드를 누르면 게시글 내용을 확인할 수 있음
