# 이벤트 스토리 모음 (한정 이벤트 스토리 아카이브)

> **URL**: https://jforplay.github.io/altoy/story-viewer/event-story/
>
> **내비게이션 바 위치**: 스토리보기 → 기타 스토리 컨텐츠

기간한정 이벤트 스토리들을 연도별로 모아둔 아카이브. 메인스토리 페이지에 안 실리는 소형 이벤트·복각 이벤트 스토리까지 전부 여기서 볼 수 있음.

![연도별 이벤트 그리드](/altoy/wiki-assets/EVENT_STORY/01-main.webp)
*최신 이벤트부터 연도별로 정리된 역대 한정 이벤트들*

## 주요 기능
- **연도별 정리 + 검색**: 최신 이벤트부터 연도별 섹션으로 정리, 이벤트 이름 검색 지원
- **유형/진영 필터**: E.X. / S.P. / 데일리 칩(게임 자체 분류 명칭 그대로)과 진영 필터로 골라보기
- **메인스토리 연동**: 스토리가 다른 페이지(메인스토리 등)에 이미 있는 이벤트는 배지가 붙고, 누르면 해당 페이지로 바로 이동
- 커버 일러가 없는 이벤트는 SD 일러 플레이스홀더 커버로 표시

## 스토리 감상
- **스토리 뷰어**: 메인스토리 뷰어와 같은 형태로 감상 — 일러+브금+연출, 전체 대사보기, 진행도 표시 지원
- **전체 대사 모아보기**: 이벤트의 모든 스토리 대사를 한 화면에 모아보고 전체 복사도 가능
- 스토리 재생 시 브금 자동재생 주의 알림 있음

## 스토리 화면
- **진행**: 화면을 누르면 다음 줄, 왼쪽 1/3을 누르면 이전 줄. 대사 칸 오른쪽 아래의 ‹ › 버튼으로도 넘길 수 있음. 키보드는 → / Space / Enter(다음), ←(이전). 대사 끝에 ▼가 깜빡이면 다음 줄이 있다는 뜻
- **대화창**: 인게임처럼 화면 아래 그라데이션 띠에 대사가 나오고, 인게임 대화창 초상화도 같이 표시됨. 캐릭터 일러 크기와 위치도 인게임과 같게 맞춤
- **자동 진행 (▶▶ 버튼 / A키)**: 켜두면 스토리가 끝났을 때 8초 뒤 다음 스토리로 넘어감 (다음 이야기 카드에서 취소 가능)
- **전체 대사 (목록 버튼 / L키)**: 지금 스토리의 대사 전체 보기
- **브금 (♫ 버튼)**: 누르면 재생/정지 버튼·곡 이름·볼륨 조절이 나옴. 재생 중에는 버튼의 막대가 움직임
- **Aa 보기 설정**: 글꼴(고딕/명조/둥근)·글자 크기·줄 간격·대화창 투명도·대화창 폭·타자기 효과·자동 진행 속도·브금 볼륨. 기기별로 저장됨 (휴대폰에서는 아래에서 올라오는 시트)
- **UI 숨기기 (눈 아이콘 / H키)**: 일러만 크게 보기. 화면을 누르면 다시 나타남
- **읽음 표시**: 스토리를 끝까지 보면 자동으로 읽음 체크. 회상 카드 오른쪽 위 체크박스로 직접 켜고 끌 수 있고, 챕터 카드에는 "읽은 수 / 전체"가 표시됨. 구글 드라이브 동기화 지원
