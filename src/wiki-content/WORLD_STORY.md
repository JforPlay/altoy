>

대작전(월드) 스토리 뷰어. 메인스토리 뷰어와 같은 엔진이라 사용법도 동일함 — 챕터 고르고 회상 고르면 일러/브금과 함께 감상.

## 주요 기능
- **챕터별 감상**: Chapter1(창공의 은빛 날개)부터 Chapter5(타오르는 잿불) + 정보 단편까지
- **스토리 뷰어**: 전체 대사 보기 / 진행도 표시 / 브금 재생 등 메인스토리 뷰어와 동일한 기능
- **이벤트 이름 검색** 지원

## 스토리 화면
- **진행**: 화면을 누르면 다음 줄, 왼쪽 1/3을 누르면 이전 줄. 키보드는 → / Space / Enter(다음), ←(이전)
- **대화창**: 인게임처럼 화면 아래 그라데이션 띠에 대사가 나오고, 인게임 대화창 초상화도 같이 표시됨. 캐릭터 일러 크기와 위치도 인게임과 같게 맞춤
- **AUTO (A키)**: 자동 진행. 켜두면 스토리가 끝났을 때 8초 뒤 다음 스토리로 넘어감 (다음 이야기 카드에서 취소 가능)
- **LOG (L키)**: 전체 대사 보기
- **Aa 보기 설정**: 글꼴(고딕/명조/둥근)·글자 크기·줄 간격·대화창 투명도·대화창 폭·타자기 효과·자동 진행 속도·브금 볼륨. 기기별로 저장됨 (휴대폰에서는 아래에서 올라오는 시트)
- **UI 숨기기 (눈 아이콘 / H키)**: 일러만 크게 보기. 화면을 누르면 다시 나타남
- **읽음 표시**: 스토리를 끝까지 보면 자동으로 읽음 체크. 회상 카드 오른쪽 위 체크박스로 직접 켜고 끌 수 있고, 챕터 카드에는 "읽은 수 / 전체"가 표시됨. 구글 드라이브 동기화 지원
