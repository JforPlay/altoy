# 함순이 건조확률 보기

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-build-sim/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 정보

배너별 건조확률을 확인하고 건조 시뮬레이션도 돌려볼 수 있는 미니 장난감. 위에서 보고싶은 배너를 누르면 해당 배너의 함순이 리스트랑 같이 아래에서 건조확률을 볼 수 있음.

![배너 선택](/altoy/wiki-assets/SHIPGIRL_BUILD/01-main.webp)
*소형/중형/특형 + 한정 건조 + 절망 건조 배너 선택*

## 주요 기능
- **배너 선택**: 소형함/중형함/특형함 상시 건조, 진행 중인 한정 건조, 절망 건조(소형/중형/특형)까지 전부 지원
- **픽업 리스트**: 배너를 고르면 해당 배너에서 픽업 확률이 올라가는 함순이들이 표시됨
- **절망 건조**: 픽업 함순이 직접 선택 가능
- **확률 계산**: 아래에서 확률이 궁금한 함순이를 고르면 해당 함순이의 뽑기 확률(N연차 누적 등)을 볼 수 있음

![건조 목록](/altoy/wiki-assets/SHIPGIRL_BUILD/03-rates.webp)
*배너 선택 후 픽업 함순이 추가 / 확률 확인 영역*

## 주의
- **어디까지나 표시확률에 기반한 이론치니까 뽑기는 신중하게 접근하셈...**
- 한정 배너 목록은 일정 시간마다 정리되기 때문에 지나간 배너도 한동안 보일 수 있음
- 절망 건조의 상시 무딱들은 수동 업데이트라 반영이 늦을 수 있음
