# 탄막 시뮬레이터 (스킬 탄막 시뮬레이터)

> **URL**: https://jforplay.github.io/altoy/simulators/sim-weapon/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 시뮬레이터들

각종 스킬의 탄막을 실제 게임 로직(고정 30fps 물리) 기반으로 재현해서 구경하는 시뮬레이터. 함순이 DB에서 스킬에 붙은 `무기 시뮬레이터` 링크를 누르면 여기로 와짐.

![발사 모습](/altoy/wiki-assets/SIM_WEAPON/02-firing.webp)
*스킬 선택 → 발사 — 탄막이 실제 궤적대로 날아감*

## 주요 기능
- **스킬 선택**: 1,400개+ 스킬을 검색하거나 함순이별로 브라우징해서 선택. 함순이 DB 스킬 링크로도 진입 가능 (`?skill_id=`)
- **시뮬레이션 컨트롤**: `발사`, 재생속도 0.5x/1x/2x/3x (1x = 실제 게임 속도), 일시정지, 적 위치(상단/중단 등) 조절, 스킬 레벨 조절
- **무기 정보**: 선택한 스킬의 탄종, 데미지(+배율), 장전 시간, 사거리, 관통, 경장/중장/중장갑 계수까지 표로 확인 가능
- **탄막 종류**: 직선형 포격/어뢰/유도탄/낙하 폭탄 등 대부분의 공격 탄막이 구현됨

## 주의
- 일부 특수 탄막(레이저류 이펙트 등)은 아직 완벽하게 재현 안 된 게 있음
- 스킬 발동 주기는 실제 게임의 쿨다운 기준이라 무기 사속과 다를 수 있음 (게임 그대로임)
