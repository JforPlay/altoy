# 함순이별 스토리 찾기 (등장 회상 검색)

> **URL**: https://jforplay.github.io/altoy/story-viewer/story-search/
>
> **내비게이션 바 위치**: 스토리보기 → 기타 스토리 컨텐츠

"얘 나오는 스토리 어디였더라"를 해결하는 페이지. 함순이 이름만 넣으면 메인스토리 · 이벤트 스토리 · 대작전 스토리에 흩어져 있는 등장 회상을 한 번에 모아서 보여줌. 세 뷰어를 각각 뒤질 필요 없음.

![기본 화면](/altoy/wiki-assets/STORY_SEARCH/01-main.webp)
*검색 전에는 등장 회상이 많은 함순이들이 먼저 보임*

## 주요 기능
- **이름 검색**: 왼쪽 검색창에 함순이 이름 입력 — 오타나 로마숫자 표기(Ⅲ/III) 차이도 어느 정도 잡아줌
- **바로 선택**: 검색하면 제일 위 결과가 자동으로 선택돼서 회상 목록이 바로 뜸
- **함순이 정보**: 고른 함순이의 일러와 함께 희귀도 · 진영을 같이 표시
- **출처별 정리**: 오른쪽 목록은 메인스토리 / 이벤트 스토리 / 대작전 스토리로 나뉘고, 각 묶음마다 개수 표시
- **이벤트 등급 표시**: 이벤트 스토리 회상에는 E.X. / S.P. / 데일리 배지가 붙어서 어떤 규모의 이벤트였는지 바로 보임
- **한 번에 이동**: 회상을 누르면 해당 스토리 뷰어의 그 장면이 바로 열림
- 이름 옆 숫자는 그 함순이의 총 등장 회상 수

![검색 결과](/altoy/wiki-assets/STORY_SEARCH/02-search.webp)
*이름을 넣으면 등장 회상이 출처별로 정리돼서 나옴*

## 팁
- 함순이뿐 아니라 스토리에 나오는 NPC(네비게이터-TB 같은)도 같이 검색됨
- 주소창의 `?gid=` 값이 선택한 함순이를 기억하므로, 그 상태 그대로 링크를 공유할 수 있음
- 대사가 하나도 없는 순수 나레이션 회상은 등장인물이 없으므로 목록에 안 잡힘
- 스킨이 여러 개인 함순이도 하나로 묶여서 집계됨 (수영복 스킨으로 나온 장면도 같이 나옴)
