# 장비 스킨 뷰어 (장비스킨 시뮬레이터)

> **URL**: https://jforplay.github.io/altoy/skin/equip-skin-viewer/
>
> **내비게이션 바 위치**: 정보/도구모음 → 장비 관련

장비 스킨을 테마별로 골라서 실제 발사 모습을 미리 볼 수 있는 시뮬레이터.

![테마 선택](/altoy/wiki-assets/EQUIP_SKIN/02-theme.webp)
*테마 선택 → 테마에 속한 스킨 목록 → 발사 미리보기*

## 주요 기능
- **테마 목록**: 90개+ 장비 스킨 테마, 테마 검색 지원
- **발사 미리보기**: 스킨을 고르고 `발사`를 누르면 위 시뮬레이션 화면에서 해당 스킨의 탄막이 나가는 모습을 볼 수 있음
- **재생 컨트롤**: 반복 재생, 0.5x/1x/2x/3x 속도 조절, 일시정지
- **URL 공유**: `?theme=번호&skin=번호`로 특정 스킨 바로가기 가능

## 팁
- 속도는 0.5배로 보는게 구경하기 더 좋을 수 있음
