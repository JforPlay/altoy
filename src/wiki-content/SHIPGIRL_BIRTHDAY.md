# 함순이 생일

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-birthday/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 정보

함순이 생일(= 원본 배 진수일)을 달력으로 모아볼 수 있는 페이지.

![연간 달력](/altoy/wiki-assets/SHIPGIRL_BIRTHDAY/01-main.webp)
*연간 보기 — 날짜별 생일 함순이 수가 뱃지로 표시됨*

## 주요 기능
- **달력 보기 전환**: 연간 / 월간 / 주간 / 일간 4가지 보기 지원, `오늘` 버튼으로 바로 복귀
- **함순이 검색**: 이름으로 검색해서 특정 함순이 생일 바로 찾기
- **다가오는 생일**: 오른쪽 아래 둥근 버튼을 누르면 다가오는 생일 목록을 보여줌
- **DB 연동**: 함순이 그림을 누르면 함순이 DB 상세 페이지로 이동
