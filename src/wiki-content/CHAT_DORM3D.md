# 3D숙소 JUUS (벽람항로 3D숙소 쥬톡)

> **URL**: https://jforplay.github.io/altoy/chat-viewer/dorm3d/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 소셜 컨텐츠

3D 숙소에서 발생하는 쥬톡들을 모아둔 대화형 뷰어. 일반 쥬톡 뷰어(JUUS 보기)와 사용법이 동일함.

![캐릭터 선택](/altoy/wiki-assets/CHAT_DORM3D/01-main.webp)
*3D 숙소가 있는 함순이들 (뉴저지, 앵커리지, 시리우스, 노시로, 다이호, 에기르)*

## 주요 기능
- **캐릭터 선택**: 3D 숙소가 구현된 함순이들의 쥬톡을 골라볼 수 있음
- **대화형 진행 + 해금조건**: 에피소드 선택, 해금 조건 표시, 선택지 진행 모두 일반 쥬톡 뷰어와 동일
