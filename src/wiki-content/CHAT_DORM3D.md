# 3D숙소 JUUS (벽람항로 3D숙소 쥬톡)

> **URL**: https://jforplay.github.io/altoy/chat-viewer/dorm3d/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 소셜 컨텐츠

3D 숙소에서 발생하는 쥬톡들을 모아둔 뷰어. 일반 쥬톡 뷰어(JUUS 보기)와 화면 구성과 사용법이 같음.

![대화방 목록](/altoy/wiki-assets/CHAT_DORM3D/01-main.webp)
*3D 숙소가 있는 함순이들의 대화방 목록*

## 주요 기능
- **대화방 목록 + 검색**: 3D 숙소가 구현된 함순이들의 쥬톡을 골라보거나, 이름 · @아이디 · 대사로 찾을 수 있음
- **재생 / 전체 대본**: 메시지가 하나씩 도착하는 재생 모드와 대본을 한 번에 펼쳐보는 전체 대본 모드를 오갈 수 있음
- **해금 조건 + 선택지**: 스토리 탭, 해금 조건 표시, 선택지 진행 모두 일반 쥬톡 뷰어와 동일
