# JUUS 보기 (벽람항로 쥬톡 뷰어)

> **URL**: https://jforplay.github.io/altoy/chat-viewer/juus/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 소셜 컨텐츠

함순이들의 쥬톡(메신저 대화)을 대화형 뷰어로 구경하는 페이지. 캐릭터 고르고 스토리 고르면 실제 메신저처럼 선택지 눌러가면서 진행됨.

![캐릭터 선택](/altoy/wiki-assets/CHAT_JUUS/01-main.webp)
*1. 캐릭터/그룹 선택 그리드*

## 주요 기능
- **캐릭터/그룹 선택**: 쥬톡이 있는 함순이들을 골라서 진입
- **스토리 선택 + 해금조건**: 캐릭터의 쥬톡 에피소드를 드롭다운에서 고를 수 있고, 인게임 해금 조건(호감도 등)도 같이 표시됨
- **대화형 진행**: 클릭하면 메시지가 하나씩 도착하고, 중간중간 지휘관 선택지를 직접 골라서 진행함. `다시 재생하기`로 처음부터 다시 볼 수 있음
- **스티커**: 대화 중 나오는 스티커도 구현되어 있음 (움짤 이모티콘 제외)
