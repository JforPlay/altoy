# 만화 보기 (Comic Viewer)

> **URL**: https://jforplay.github.io/altoy/misc/comic-viewer/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 인게임 일러스트들

인게임 만화 모음. 원본 크기로 저장하고 싶은 사람한테 유용함.

![만화 목록](/altoy/wiki-assets/COMIC_VIEWER/01-main.webp)
*만화 썸네일 그리드*

## 주요 기능
- **정렬**: 1호부터 / 최신호부터 정렬 전환
- **확대 보기**: 누르면 라이트박스로 크게 보여줌
