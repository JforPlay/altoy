# TB 키우기 (TB키우기 한눈에 보기)

> **URL**: https://jforplay.github.io/altoy/story-viewer/tb-story/
>
> **내비게이션 바 위치**: 스토리보기 → 딸내미 키우기

통베(TB) 키우기 콘텐츠의 회상/엔딩/수집요소를 모아둔 페이지. 네비/로라 키우기와 같은 구조임.

![TB 키우기](/altoy/wiki-assets/TB_STORY/01-main.webp)
*탭(회상/엔딩/조각들/일상/플레이리스트/기타 사진들) + 회상 카드*

## 주요 기능
- **회상/엔딩 감상**: 카드를 누르면 스토리 뷰어로 열려서 브금과 함께 감상 가능 (전체 대사 보기/진행도 표시 포함)
- **수집요소 탭**: TB의 조각들, TB의 일상, 플레이리스트, 기타 이미지들까지 키우기 관련 에셋이 한곳에 모여있음

![회상 감상](/altoy/wiki-assets/TB_STORY/02-story.webp)
*회상 스토리 뷰어 화면*

## 스토리 화면
- **진행**: 화면을 누르면 다음 줄, 왼쪽 1/3을 누르면 이전 줄. 키보드는 → / Space / Enter(다음), ←(이전)
- **대화창**: 인게임처럼 화면 아래 그라데이션 띠에 대사가 나오고, 인게임 대화창 초상화도 같이 표시됨. 캐릭터 일러 크기와 위치도 인게임과 같게 맞춤
- **AUTO (A키)**: 자동 진행. 켜두면 스토리가 끝났을 때 8초 뒤 다음 스토리로 넘어감 (다음 이야기 카드에서 취소 가능)
- **LOG (L키)**: 전체 대사 보기
- **Aa 보기 설정**: 글꼴(고딕/명조/둥근)·글자 크기·줄 간격·대화창 투명도·대화창 폭·타자기 효과·자동 진행 속도·브금 볼륨. 기기별로 저장됨 (휴대폰에서는 아래에서 올라오는 시트)
- **UI 숨기기 (눈 아이콘 / H키)**: 일러만 크게 보기. 화면을 누르면 다시 나타남
- **읽음 표시**: 스토리를 끝까지 보면 자동으로 읽음 체크. 회상 카드 오른쪽 위 체크박스로 직접 켜고 끌 수 있고, 챕터 카드에는 "읽은 수 / 전체"가 표시됨. 구글 드라이브 동기화 지원
