# 설비스킨 (벽람항로 설비스킨 뷰어)

> **URL**: https://jforplay.github.io/altoy/skin/skin-sd-viewer/
>
> **내비게이션 바 위치**: 정보/도구모음 → 장비 관련

장비(설비) 스킨의 스파인 애니메이션을 재생해볼 수 있는 뷰어. 캐릭터 SD는 샘플로 3개만 들어있음.

![캐릭터 애니메이션](/altoy/wiki-assets/SKIN_SD/02-selected.webp)
*캐릭터/설비 선택 → 애니메이션 목록(attack, dance, dead 등) 재생*

## 주요 기능
- **설비 스킨 보기**: 설비 스킨들의 SD 애니메이션을 전부 확인 가능
- **애니메이션 선택**: attack / dance / move 같은 모션 목록에서 골라서 재생
- **디스플레이 모드**: 캐릭터만 / 장비만 / 둘 다 표시 전환

## 참고
- 함순이 SD는 샘플 3개뿐이고 더 추가할 예정은 없음
- 깨져서 빠진 설비가 하나 있음 — 그 외 빠진 게 보이면 제보 부탁
