# 지원 탄막 시뮬레이터 (타함대 지원/공격스킬)

> **URL**: https://jforplay.github.io/altoy/simulators/cross-fleet-barrages/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 시뮬레이터들

다른 함대를 지원하는 스킬(지원 탄막/버프)들만 모아둔 페이지. 어떤 함순이가 어떤 조건으로 타함대에 탄막/버프를 쏴주는지 표로 정리되어 있고, 탄막은 바로 시뮬레이션으로 구경 가능.

![지원 탄막 목록](/altoy/wiki-assets/CROSS_FLEET_BARRAGES/01-main.webp)
*함순이/스킬/진영/타입/트리거 표 + 행별 시뮬레이션 버튼*

## 주요 기능
- **지원 스킬 카탈로그**: 후소·META, 무츠키改 등 타함대 지원 스킬 33종(탄막 25 + 버프 8)을 한 곳에 정리
- **트리거 조건**: 각 스킬이 언제 발동하는지(전투 시작 N초 후, 몇 번째 함대 진입 시 등) 설명이 그대로 적혀있음
- **필터**: 진영(META/노스 유니온/로열 네이비 등)과 타입(탄막/버프)으로 추려보기
- **시뮬레이션**: 탄막 스킬은 행의 `시뮬레이션` 버튼을 누르면 위 화면에서 바로 발사됨 — 속도/적 위치 조절도 탄막 시뮬레이터와 동일
