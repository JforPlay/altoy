# 아일랜드 계획 관리 (무인도 관리 / 벽타듀)

> **URL**: https://jforplay.github.io/altoy/island/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 계산기/도구

벽타듀(아일랜드) 콘텐츠 관리 페이지. 캐릭터/기술/퀘스트/자원/레스토랑/시즌 계산기를 탭으로 나눠놨고, 제일 쓸모있는 건 연구(기술) 재화 관리 — 후반으로 갈수록 재화와 골드를 많이 먹어서 미리 계획 세우기 좋음.

![캐릭터 탭](/altoy/wiki-assets/ISLAND/01-main.webp)
*캐릭터 탭 — 작업 만쥬 포함 캐릭터 목록과 상세 정보*

## 주요 기능
- **캐릭터 탭**: 아일랜드 캐릭터들의 상세 정보, 스탯, 스킬, 스킨 확인
- **기술 탭**: 기술 트리를 분류(본부 인증/채집/재배/사육/요리/제조)별로 보고, 완료 체크하면 필요 재화가 알아서 차감됨. 체크는 브라우저에 저장되니까 계속 관리 가능
- **퀘스트 탭**: 퀘스트 목록/조건 확인
- **자원 탭**: 아이템/재료 정보
- **레스토랑 탭**: 메뉴별 판매 효율 확인 — 거의 다 효율 95% 이상이라 뭘 만들어 팔아도 큰 상관 없음
- **시즌 계산기 탭**: 현재 개발 시즌(시즌Ⅲ — 여름 특산물 경영)의 시즌 포인트 계산기. 보유 아이템/재료 기준 총 포인트 계산 + 보상 트래킹
