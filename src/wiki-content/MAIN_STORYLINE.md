# 메인스토리 타임라인

> **URL**: https://jforplay.github.io/altoy/story-viewer/main-storyline/
>
> **내비게이션 바 위치**: 스토리보기 → 주요 스토리

메인스토리의 흐름을 타임라인(분기 그래프)으로 보여주는 페이지. 어떤 스토리가 어떤 순서로 이어지는지 한눈에 보고, 카드를 누르면 바로 해당 스토리를 보러 갈 수 있음.

![타임라인](/altoy/wiki-assets/MAIN_STORYLINE/01-main.webp)
*스토리 카드들이 선으로 연결된 타임라인 + 하단 장 네비게이션*

## 주요 기능
- **타임라인 그래프**: 스토리 카드들이 시간순/분기 구조로 연결되어 있음
- **장 네비게이션**: 아래의 서장/제1장/제2장... 메뉴를 눌러서 해당 구간으로 점프
- **검색 / 진영 필터**: 스토리 검색이랑 진영별 필터링 지원
- **전체스토리 보기**: 왼쪽 위 버튼으로 메인스토리 뷰어로 이동
