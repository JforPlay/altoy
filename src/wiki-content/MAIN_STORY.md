# 메인스토리 (벽람항로 메인스토리 뷰어)

> **URL**: https://jforplay.github.io/altoy/story-viewer/main-story/
>
> **내비게이션 바 위치**: 스토리보기 → 주요 스토리

메인스토리 전체를 일러스트/표정/연출/브금과 함께 감상할 수 있는 스토리 뷰어. 챕터 카드 → 회상 목록 → 스토리 순으로 들어가면 됨.

![챕터 목록](/altoy/wiki-assets/MAIN_STORY/01-main.webp)
*챕터(스토리) 카드 그리드 + 검색*

## 주요 기능
- **스토리 진행**: 인게임 연출(암전, 흔들림, 플래시, 효과음 등) 중 단순한 것들은 같이 재현되어 있음
- **브금 재생**: 스토리에 맞춰 브금이 자동 재생됨 (최저 볼륨 1%로 시작 + 재생 경고 표시). 오른쪽 위 ♫ 버튼을 누르면 재생/정지와 볼륨 조절 (보기 설정 Aa에서도 볼륨 조절 가능)
- **전체 대사 보기**: 위쪽 버튼으로 하나씩 클릭할 필요 없이 전체 대사를 한 번에 볼 수 있음
- **진행도 표시**: 현재 스토리 진행도가 위에 표시됨
- **다음 스토리 이어보기**: 다 보면 마지막 화면의 "다음 이야기" 카드로 다음 회차를 이어서 볼 수 있음
- **검색 / 타임라인**: 스토리 검색 + 메인스토리 타임라인 페이지로 바로 이동 가능
- **URL 공유**: `?eventid=&story=`로 특정 회상 바로 공유 가능

## 스토리 화면
- **진행**: 화면을 누르면 다음 줄, 왼쪽 1/3을 누르면 이전 줄. 대사 칸 오른쪽 아래의 ‹ › 버튼으로도 넘길 수 있음. 키보드는 → / Space / Enter(다음), ←(이전). 대사 끝에 ▼가 깜빡이면 다음 줄이 있다는 뜻
- **대화창**: 인게임처럼 화면 아래 그라데이션 띠에 대사가 나오고, 인게임 대화창 초상화도 같이 표시됨. 캐릭터 일러 크기와 위치도 인게임과 같게 맞춤
- **자동 진행 (▶▶ 버튼 / A키)**: 켜두면 스토리가 끝났을 때 8초 뒤 다음 스토리로 넘어감 (다음 이야기 카드에서 취소 가능)
- **전체 대사 (두루마리 버튼 / L키)**: 지금 스토리의 대사 전체 보기
- **브금 (♫ 버튼)**: 누르면 재생/정지 버튼·곡 이름·볼륨 조절이 나옴. 재생 중에는 음표에 색이 들고 옆의 작은 막대가 움직임
- **Aa 보기 설정**: 글꼴(고딕/명조/둥근)·글자 크기·줄 간격·대화창 투명도·대화창 폭·타자기 효과·자동 진행 속도·브금 볼륨. 기기별로 저장됨 (휴대폰에서는 아래에서 올라오는 시트)
- **UI 숨기기 (눈 아이콘 / H키)**: 일러만 크게 보기. 화면을 누르면 다시 나타남
- **읽음 표시**: 스토리를 끝까지 보면 자동으로 읽음 체크. 회상 카드 오른쪽 위 체크박스로 직접 켜고 끌 수 있고, 챕터 카드에는 "읽은 수 / 전체"가 표시됨. 구글 드라이브 동기화 지원

## 참고
- 전투씬이 여러 번 끼는 스토리는 다 이어붙여놔서, 중간에 브금이 뜬금없이 바뀌면 전투 한 번 하고 왔구나 생각하면 됨
