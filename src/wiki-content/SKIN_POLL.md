# 스킨 투표 (벽챈 스킨 선호도 투표)

> **URL**: https://jforplay.github.io/altoy/skin/skin-poll/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 스킨 & 대사

벽챈 스킨 선호도를 실시간으로 투표하고 구경하는 페이지. 투표하면 기록이 계속 남아서 자기가 과거에 했던 투표 결과랑 스킨들의 현재 투표 현황을 볼 수 있음.

![스킨 투표](/altoy/wiki-assets/SKIN_POLL/01-main.webp)
*필터 + 투표 카드 목록*

## 주요 기능
- **실시간 투표**: 스킨별로 평점 투표 가능, 결과는 실시간 동기화됨
- **내 투표 기록**: 과거에 투표한 내역이 남아서 다시 볼 수 있음
- **리더보드 (Top 스킨 보기)**: 10표 이상 받은 스킨들은 위 리더보드에 평점순으로 표시됨
- **필터**: 함순이 이름 / 스킨 타입 / 진영 / 스킨 태그 / 페이지 정렬 등으로 추려볼 수 있음
