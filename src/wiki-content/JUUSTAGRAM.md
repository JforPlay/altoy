# JUUSTAGRAM (쥬스타그램 뷰어)

> **URL**: https://jforplay.github.io/altoy/juustagram/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 소셜 컨텐츠

룽섭에 들어가 있는 모든 쥬스타그램 게시글을 볼 수 있는 페이지. 포스트 작성자/댓글 작성자 검색이 돼서 원하는 함순이가 나오는 글만 찾아볼 수 있음.

![쥬스타그램](/altoy/wiki-assets/JUUSTAGRAM/01-main.webp)
*피드 + 작성자/댓글 작성자 검색 + 오른쪽 스티커 모음*

## 주요 기능
- **전체 게시글 보기**: 사진 + 본문 + 댓글 전부 확인 가능, 지휘관 댓글(선택지)도 있음
- **검색**: 포스트 작성자로 찾기 / 댓글 작성자로 찾기 둘 다 지원
- **스티커 모음**: 쥬스타그램에서 쓰이는 함순이 스티커(이모티콘)들도 옆에 모아져 있음
