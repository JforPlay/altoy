# 함순이 육성트래커 (기술/진영점수 계산기)

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-tracker/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 트래커

육성 현황 + 기술점수/진영점수 작업용 트래커. 함순이별로 보유/풀돌/Lv120을 체크해두면 위에서 알아서 합산해줘서, 함종별 기술점수작 확인용으로도 진영점수 계산기로도 쓸 수 있음. 체크 말고도 육성 레벨(성정 유닛), 개장, 호감작, 스작, 메모까지 같이 기록할 수 있어서 "얘 뭐까지 해놨더라"를 한 곳에서 관리 가능.

*카드형 보기 — 체크박스 + 육성 레벨 바 + 기타 육성 칩*

## 세 가지 보기

오른쪽 위 **보기 전환** 버튼을 누를 때마다 **카드형 → 요약형 → 목록형** 순으로 돌아감. 어느 보기에서 뭘 바꾸든 같은 기록이라 서로 그대로 반영됨.

- **카드형** — 기본값. 함순이 한 명당 카드 하나에 모든 항목이 다 보임
- **목록형** — 한 줄에 한 명. 표처럼 쭉 훑으면서 빠르게 체크하기 좋음
- **요약형** — 전체를 작은 타일로. 지금 어디까지 해놨는지 한눈에 보는 용도

*목록형 보기 — 한 줄에 한 명씩*

## 요약형 보기 (한눈에 보기 + 빠른 기록)

![요약형 보기](/altoy/wiki-assets/SHIPGIRL_TRACKER/03-wall.webp)
*요약형 보기 — 지표를 고르면 타일 밑 막대가 그 지표의 진행도*

- **지표**: **육성 레벨 / 스작 / 호감작** 중에 하나를 고르면 타일 아래 막대가 그 지표의 진행도를 표시함. 지표마다 막대 색이 달라서 지금 뭘 보고 있는지 헷갈리지 않음
- **타일을 누르면 한 단계 위로** 올라감. **Shift+클릭**이나 **우클릭**(모바일은 **길게 누르기**)은 한 단계 내림. 굳이 카드를 펼치지 않아도 쭉 훑으면서 기록 가능
- **미획득** 함순이는 어떤 지표에서든 흑백으로 표시됨
- **높은 순으로 재정렬**을 누르면 진행도 높은 순으로 정렬됨. 정렬은 지표를 바꿀 때랑 이 버튼을 누를 때만 다시 계산돼서, 연속으로 타일을 누르는 동안 타일이 발밑에서 도망가지 않음

![스작 지표](/altoy/wiki-assets/SHIPGIRL_TRACKER/04-wall-skill.webp)
*같은 화면에서 지표만 스작으로 바꾼 것 — 색도 순서도 그 지표 기준으로 바뀜*

## 주요 기능

- **점수 체크**: **보유 / 풀돌 / Lv120** 세 개가 기술 Pt에 반영됨
- **육성 레벨**: **120 / 125** 각각 토글. 125를 켜면 120도 같이 켜지고, 120을 끄면 125도 같이 꺼짐. Lv120 체크와도 연동됨. 상단에 **성정 유닛 I·II** 소모량이 등급별 실제 요구량 기준으로 자동 합산됨
- **기타 육성**: **호감작**(안함 / 100 예정 / 100 완료 / 200 예정 / 200 완료), **스작**(안함 / 예정 / 진행중 / 완료), **개장**, **즐겨찾기(★)**, **메모** 기록
- **필터링**: 진영 / 함종 / 등급 / 입수 스탯 / 120렙 스탯 / 체크 상태 / 즐겨찾기 / 개장 / 호감작 / 스작 / 메모 / 이름 검색
- **자동 합산**: 체크해둔 것에 맞춰 위에서 점수를 자동 계산해줌 — 진영 필터를 걸면 진영점수 계산기가 됨
- **일괄 적용**: 필터 서랍 아래쪽에서 "모두 입수 체크" 같은 걸 누르면 **지금 필터에 걸린 목록에만** 일괄 적용됨
- **점수판 / 연구 목표**: 현재 기술·진영 점수 상세와 연구함 해금 목표 달성 현황을 따로 볼 수 있음
- **활용 예시**: 전함/장전작처럼 특정 함종의 기술점수작 확인, 연구함 해금조건(정조대) 확인 등
- **저장**: 기록은 브라우저에 저장되고, 탭 여러 개를 열어도 서로 동기화됨. 메인의 구름 아이콘으로 구글 드라이브 백업/기기간 동기화도 가능

## 시트에서 가져오기

![시트에서 가져오기](/altoy/wiki-assets/SHIPGIRL_TRACKER/06-sheet-import.webp)
*구글 시트에서 복사해 붙여넣거나 CSV 파일로 가져오기*

구글 시트로 육성표를 관리하고 있었다면 그대로 가져올 수 있음. 툴바의 **시트 가져오기** 버튼.

1. 구글 시트에서 **머리글 행을 포함해** 원하는 범위를 복사
2. 붙여넣기 칸에 붙여넣거나, 내려받은 CSV 파일을 선택
3. 미리보기에서 인식된 함순이 수를 확인하고 **적용**

- **ID 열을 기준으로** 맞춤 (`123` · `Z001` · `P001` · `M061`). 이름은 확인용으로만 쓰고 이름으로 짝을 찾지는 않음 — 표기 흔들리는 이름으로 맞추면 엉뚱한 함순이한테 들어갈 수 있어서 일부러 그렇게 함
- 읽는 열: **개장여부 / 즐겨찾기 / 획득·육성여부 / 스작여부 / 호감작여부 / 자유코멘트**. 열 순서는 상관없고, 사진·레어도·함종이나 점수 계산용 열이 섞여 있어도 그냥 무시함
- **빈 칸은 "변경하지 않음"**으로 처리돼서 기존 기록을 지우지 않음. 개장이 아예 없는 함순이처럼 시트에서 비워두는 칸이 있어도 안전함
