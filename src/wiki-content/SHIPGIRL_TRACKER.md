# 함순이 육성트래커 (기술/진영점수 계산기)

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-tracker/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 트래커

기술점수/진영점수 작업용 트래커. 함순이별로 입수/120 기술 스탯을 체크해두면 위에서 알아서 합산해줘서, 함종별 기술점수작 확인용으로도 진영점수 계산기로도 쓸 수 있음.

![트래커 메인](/altoy/wiki-assets/SHIPGIRL_TRACKER/01-main.webp)
*함순이별 체크박스 + 위쪽 필터/합계*

## 주요 기능
- **필터링**: 진영 / 함종 / 등급 / 입수+120 기술스탯 / 함순이 이름 / 트래커 체크 여부 등으로 검색 가능
- **자동 합산**: 체크해둔 것에 맞춰 위에서 점수를 자동 계산해줌 — 진영 필터를 걸면 진영점수 계산기가 됨
- **활용 예시**: 전함/장전작처럼 특정 함종의 기술점수작 확인, 연구함 해금조건(정조대) 확인 등
- **저장**: 체크 상태는 브라우저에 저장되고, 탭 여러 개를 열어도 서로 동기화됨. 메인의 구름 아이콘으로 구글 드라이브 백업/기기간 동기화도 가능
