# 기타 캐릭터 일러 뷰어 (표정 일러스트 뷰어)

> **URL**: https://jforplay.github.io/altoy/skin/expression-viewer/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 스킨 & 대사

NPC, 적(아비터 등), 스토리 전용 캐릭터들의 일러스트와 표정을 확인할 수 있는 뷰어. 클뜯 ID 기반으로 정리한 거라 함순이인데도 들어있는 경우가 종종 있음 (스토리용으로 별도 관리되는 애들).

![캐릭터 선택 후](/altoy/wiki-assets/SKIN_EXPRESSION/02-selected.webp)
*캐릭터 선택 → 표정 17개 썸네일 + 일러스트, 기본/확대 일러 전환*

## 주요 기능
- **캐릭터 목록**: 225개+ 일러스트가 ID순으로 정렬되어 있고, 이름 또는 ID로 검색 가능
- **표정 선택**: 캐릭터를 고르면 표정 차분 썸네일이 쭉 나오고, 누르면 해당 표정이 합성된 일러를 보여줌
- **기본/확대 일러 전환**: 오른쪽 위 버튼으로 전환

## 팁
- 아비터들이라던가 스토리 전용 일러가 은근 많으니 심심할 때 구경하기 좋음
