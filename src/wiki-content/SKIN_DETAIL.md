# 일러/대사 (함순이 스킨/대사 보기)

> **URL**: https://jforplay.github.io/altoy/skin/skin-detail-viewer/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 스킨 & 대사

함순이 고르고 스킨 고르면 해당 스킨의 일러스트 + 대사를 다 볼 수 있는 페이지. 선택 2번이면 끝.

![스킨 선택 후](/altoy/wiki-assets/SKIN_DETAIL/02-skin.webp)
*함순이/스킨 선택 후 — 일러스트, SD, 표정, 스킨 정보(태그/출시일)*

## 주요 기능
- **일러스트 보기**: 스킨 일러 + 확대 일러 + SD + 표정 모음까지 한 화면에서 확인
- **스킨 정보**: 스킨을 고르면 태그, 출시일 같은 정보도 같이 뜸. `i` 버튼을 누르면 tmi가 좀 더 나옴
- **대사 모음 + 음성 재생**: 아래로 내리면 입수시/상세확인/호감 등 상황별 대사가 전부 나오고, 재생 버튼으로 보이스도 들을 수 있음 (볼륨 조절 가능)
- **랜덤 스킨 구경가기**: 맨 위 버튼 → 원하는 필터를 걸고, 조건에 맞는 스킨 수를 확인한 뒤 그 안에서 랜덤으로 하나 보여줌
- **URL 공유**: `?character=이름&skin=스킨명` 형태로 특정 스킨 페이지를 바로 공유 가능
