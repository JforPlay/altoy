# 함순이 DB

> **URL**: https://jforplay.github.io/altoy/shipgirl/shipgirl-info/
>
> **내비게이션 바 위치**: 함순이/스킨/대사 → 함순이 정보

모든 함순이(866명+)의 정보를 모아둔 ALtoy의 중심 페이지. 목록에서 필터링해서 찾고, 누르면 상세 정보가 나옴. 다른 페이지(생일, 일정, 검색 등)에서 함순이를 누르면 다 여기로 연결됨.

![메인 목록](/altoy/wiki-assets/SHIPGIRL_INFO/01-main.webp)
*갤러리형 목록 + 상단 필터/검색*

## 주요 기능
- **목록 화면**: 등급/함종/진영 등 필터링 + 이름 검색, 목록형/갤러리형 보기 전환 가능. 건조시간 정보도 통합되어 있어서 목록에서 바로 확인됨
- **상세 페이지**: 함순이를 누르면 등급/함종/장갑/진영, 드랍 정보(상시 건조 여부 포함), 선호하는 선물(좋아하는/싫어하는), 능력치 계산기(레벨 슬라이더), 장비 효율(슬롯별 효율/포좌, 한계돌파 변화), 스킬 설명까지 쭉 나옴
- **스킬 → 탄막 시뮬레이터 연동**: 스킬에 `무기 시뮬레이터` 배지가 붙어있으면 클릭해서 해당 스킬의 탄막을 탄막 시뮬레이터에서 바로 구경 갈 수 있음
- **스킨/대사 보러가기**: 상세 페이지에서 버튼 하나로 해당 함순이의 스킨 뷰어로 이동
- **드랍 지역 보기**: 메인 해역 한정으로 드랍 지역이 정리되어 있고, 드랍지역을 누르면 해당 함순이 전용 드랍 페이지로 볼 수 있음
- **좌우 이동**: 상세 페이지 위쪽 화살표로 목록에서 걸어둔 필터링 순서 그대로 이전/다음 함순이로 이동 가능
- **URL 공유**: `?ship=함순이이름` 형태로 상세 페이지 주소를 그대로 공유할 수 있음
