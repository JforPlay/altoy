# 장비 DB

> **URL**: https://jforplay.github.io/altoy/equip/equip-viewer/
>
> **내비게이션 바 위치**: 정보/도구모음 → 장비 관련

전체 장비(1,100개+)를 검색/필터링하고 상세 스탯을 확인하는 장비 도감. 장비 비교 기능까지 있음.

![장비 목록](/altoy/wiki-assets/EQUIP_VIEWER/01-main.webp)
*분류 필터칩 + 장비 종류별 그리드*

## 주요 기능
- **분류 필터**: 위쪽 필터칩으로 함포/어뢰/함재기/설비 등 장비 분류별로 추려볼 수 있고 검색도 됨
- **상세 패널**: 장비를 누르면 오른쪽에 스탯, 강화(+레벨별) 수치, 탄종, 사속, 데미지 등 상세 정보가 나옴 — 함재기는 무장(폭장/기총) 구성까지 풀어서 보여줌
- **장비 비교**: 비교하기로 여러 장비를 나란히 놓고 스탯을 비교할 수 있음
- **URL 공유**: `?equip=ID`로 특정 장비, `?compare=`로 비교 상태도 공유 가능
