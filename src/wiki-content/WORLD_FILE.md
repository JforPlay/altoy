# 대작전 파일 (대작전 파일 문서 뷰어)

> **URL**: https://jforplay.github.io/altoy/story-viewer/world-file/
>
> **내비게이션 바 위치**: 스토리보기 → 주요 스토리

파일 기록기 등으로 대작전(파일해역)에서 해금되는 파일 문서들을 모아둔 뷰어. 세계관 설정 좋아하면 볼만한 게 많음.

![파일 목록](/altoy/wiki-assets/WORLD_FILE/01-main.webp)
*왼쪽 파일 썸네일 목록 → 오른쪽 본문*

## 주요 기능
- **파일 모아보기**: UNCONFIRMED/INFORMATION 등 대작전 파일 문서들을 왼쪽 목록에서 골라서 열람
- **요약본**: 하나즈키 요약 + 구글 Gemini 통번역본도 들어있어서 풀버전 읽기 전에 흐름 잡기 좋음
- **글자 크기 조절**: 오른쪽 위 +/- 버튼
