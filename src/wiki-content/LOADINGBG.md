# 로딩일러 (Loading Backgrounds)

> **URL**: https://jforplay.github.io/altoy/misc/loadingbg/
>
> **내비게이션 바 위치**: 인게임 컨텐츠 → 인게임 일러스트들

인게임 로딩 일러스트 모음. 클라이언트에 있는 것만 모아둔 거라 몇 개는 원본이 아닐 수 있음 — 더 많이 보려면 글섭/중섭 위키 추천.

![로딩일러](/altoy/wiki-assets/LOADINGBG/01-main.webp)
*로딩 일러 그리드 + 검색*

## 주요 기능
- **일러 모아보기**: 그리드로 쭉 보기, 누르면 크게 보기
- **검색**: 이미지 이름으로 검색 가능
