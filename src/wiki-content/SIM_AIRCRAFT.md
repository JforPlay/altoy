# 함재기 시뮬레이터

> **URL**: https://jforplay.github.io/altoy/simulators/sim-aircraft/
>
> **내비게이션 바 위치**: 정보/도구모음 → 각종 시뮬레이터들

탄막 시뮬레이터의 함재기 버전. 함재기가 날아가서 폭장/뇌격을 떨구는 모습을 구경할 수 있음.

![함재기 발진](/altoy/wiki-assets/SIM_AIRCRAFT/02-firing.webp)
*함재기 발진 → 비행 → 무장 투하*

## 주요 기능
- **함재기 선택**: 전투기/뇌격기/폭격기/수상기 필터 + 목록(166종)에서 선택. `?equip=장비ID`로 바로 진입도 가능
- **무장 정보**: 무기별 탄종/데미지/장전/사거리/장갑 계수 확인
- **시뮬레이션 컨트롤**: 발사, 0.5x~3x 속도, 적 위치 조절 등 탄막 시뮬레이터와 동일

## 참고
- 집속/평형 뇌격기 비교나 살포 타이밍 확인 용도로 쓸만함. 타이밍이 아직 살짝 미묘한 부분은 있을 수 있음
